# Day 8: JavaScript Conditions and Decision Making

## What I Learned
- How to use if and else statements.
- How to compare values using ===.
- How to use >= to check eligibility.
- How JavaScript makes decisions based on conditions.

## Practice Code

let age = 17;

if (age >= 18) {
    console.log("You are eligible!");
} else {
    console.log("You are not eligible yet!");
}

## Expected Output
You are not eligible yet!

## Key Lesson
JavaScript executes different blocks of code
depending on whether a condition is true or false.
